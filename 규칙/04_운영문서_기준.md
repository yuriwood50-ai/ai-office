# 운영문서 기준 — 최신 버전을 따라요

대상: `{블로그}`의 지침 문서 (읽기 전용).
확인일: 2026-10-23. 이 표는 **그날 확인한 값**이고, 문서는 앞으로 개정될 수 있어요. 직원은 표를 믿지 말고 문서 맨 위의 내부 버전·기준일을 직접 확인해요.

## 원칙
1. **파일명이 아니라 문서 내부 버전과 기준일**을 기준으로 해요. 파일명의 `v1.0`은 믿지 않아요 (개정되어도 파일명은 유지돼요).
2. 문서가 서로 다르면 N번폴더 지침 1절의 순서를 따라요: ① 작가님의 현재 요청과 최신 확정 사항 → ② N번폴더 지침 → ③ `00_운영문서`의 분야별 최신 지침.
3. 같은 급의 문서끼리 다르면 **기준일이 더 최신인 쪽**을 따르고, 다르다는 사실을 작가님께 보고해요. 직원이 문서를 고쳐서 맞추지 않아요.
4. 아래 '표의 버전보다 높은 문서'는 개정된 거예요. 높은 쪽을 따라요. **낮은 문서**를 발견하면 작업을 멈추고 보고해요.
5. 사용하지 않는 문서: `99_보관/` 안의 모든 문서와 옛 사본, `홍보스테이션 구현 설계서 v0.x 검토보고서` 3종 (2026-09 작성, 당시 지침 버전 기준이라 낡았어요), `홍보스테이션_기획서_v0.7.pdf`. `00_운영문서\smartbeetip-blog-skill-rebuilt\`는 N번폴더 지침이 참조하지 않는 별도 자료라 직원이 쓰지 않아요.
