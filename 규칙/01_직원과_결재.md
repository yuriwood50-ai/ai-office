# 직원과 결재

기준 문서: 꿀벌블로그 `N번폴더 자동제작 운영 지침` (내부 v1.11) 2절. 이 문서는 지침을 고치지 않고, 스튜디오에서 누가 어느 단계를 맡는지만 정해요.

## 팀장(작가님)의 역할
**승인과 반려만 해요.** 직접 검수하거나 파일을 만들지 않아요. 화면에서 버튼을 누르는 자리예요.

## 직원 5명

| 직원 | 담당 AI | 지침 단계 | 산출물 | 카드 |
|---|---|---|---|---|
| 주제기획 | Codex | 1~3 | 주제 후보·추천, 승인 후 주제확정서·조사메모 | `직원/주제기획.md` |
| 글쓰기 | Claude Code | 4~6 | 원고, 게시글, 읽는 대본, 이미지 인계본 | `직원/글쓰기.md` |
| 블로그이미지 | Codex | 7~8 | 블로그 이미지 후보, 검수 보고서 | `직원/블로그이미지.md` |
| 인스타카드 | Codex | 9 | 인스타 카드 후보, 검수 보고서 | `직원/인스타카드.md` |
| 마감 | Claude Code | 10~14 | 최종 폴더, 전체 미리보기, 검수메모 | `직원/마감.md` |

## 흐름과 팀장 결재

```
주제기획 ─① 기획 승인─ 글쓰기 ─② 이미지 인계 승인─ 블로그이미지 ─┐
                                                  └─ 인스타카드 ──┴─ 마감 ─④ 완료 확인─⑤ 디자인·게시 승인
```

| 결재 | 시점 | 승인하면 | 반려하면 |
|---|---|---|---|
| ① 기획 승인 | 주제기획이 주제확정서를 낸 뒤 | 글쓰기 시작 | 주제기획이 다시 작성 |
| ② 이미지 인계 승인 | 글쓰기가 인계본을 낸 뒤 | 이미지 직원 실행 (인계본 확정, 이후 원고 수정 금지) | 글쓰기가 인계본·원고 수정 |
| ④ 완료 확인 | 마감이 검수를 마치고 최종 폴더를 저장한 뒤 | "N번폴더 완료" 표시 | 마감이 지적 사항 처리 |
| ⑤ 디자인·게시 승인 | ④ 이후, 별도 단계 | 발행 단계로 이동 (발행 자체는 이 규칙의 범위 밖) | 이유를 남기고 수정 |

- **결재 ③은 없어요.** 이미지 결과 확인(독립 재검수)은 팀장이 아니라 **마감**이 해요. 번호는 기존 표와 맞추려고 비워뒀어요.
- ① 승인된 주제는 중간에 다시 승인받지 않아요 (지침 1절).
- 완료(④)와 발행(⑤ 이후)은 구분해요 (지침 13절).

## 같은 AI끼리 검수할 때
글쓰기와 마감은 둘 다 Claude Code예요. 자기 글을 자기가 검수하지 않도록 **마감은 글쓰기와 다른 세션**으로 실행하고, 앞선 대화 기억 없이 인계본과 실제 파일만 보고 판단해요.

## 반려 흐름
- 마감 → 이미지 직원: 이미지 번호, 문제 위치, 기대 결과를 적어서 돌려보내요. 이미지 직원이 부분 수정 → 재렌더링 → 자체 검수 후 다시 마감에게 가요 (지침 2-1절).
- 마감 → 글쓰기: 원고·사실 문제는 마감이 고치지 않고 글쓰기에게 돌려보내요. 원고가 바뀌면 인계본 해시를 갱신하고 ② 승인부터 다시 받아요.
