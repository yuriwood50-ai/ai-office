## 확인된 제약
GH `https://www.gh.or.kr/robots.txt`의 `User-agent: * / Disallow: /`를 실제 확인했어요. 자동 수집은 제한으로 기록하며 우회하지 않아요. 화면에서 공식 링크를 여는 것은 가능해요. 실제 GH 페이지와 삽입 상세는 읽기 점검에서 확인했지만 자동 수집 성공으로 집계하지 않아요.

출처 13개 등록은 전체 필수 출처 등록을 뜻하지 않아요. 각 동·도서관·운영기관 전수 목록, 검색엔진 교차탐색, 사이트별 목록·본문·페이지 넘김 수집기, 기존 접수 중 공고 전체 재점검, 정기 실행 예약은 후속 작업이 남아요. 목록 구조를 읽지 못하면 실패, 30일 범위를 확인하지 못하면 부분 확인으로 표시해요.

실제 AI 호출은 이번 작업에서 0회예요. 실제 인증과 응답 성공, 모든 첨부 형식은 실측하지 않았어요. 연결 코드를 만들었다는 이유만으로 실운영 완료라고 표시하지 않아요.

## 검증
기존 단위 시험 24개, 서버 통합 시험 15개, 분야·플랫폼시티·날짜·공식 본문·robots 신규 시험 10개를 통과했어요. 시험 서버는 별도 포트·별도 저장소와 실제 호출 차단 장치를 사용해요. 운영 서버를 종료하거나 POST 시험 대상으로 쓰지 않았어요.

브라우저에서 3종 선택, 플랫폼시티 그룹, 지침 화면을 확인해요. 실제 화면 확인은 시험 모드임을 표시한 별도 서버로 수행해요.
