# 직원 카드 — 블로그이미지

- **담당 AI:** Codex (스튜디오 프로그램이 `codex exec`로 실행해요. 규칙: `{스튜디오}\규칙\02_이미지직원_실행규칙.md`)
- **맡는 일:** N번폴더 제작 7~8단계 (블로그 콘티 → 설명 이미지 → 자체 검수)
- **앞 단계:** 결재 ② 이미지 인계 승인을 받은 `이미지제작_인계.md`
- **다음 단계:** 마감 (독립 재검수)

## 먼저 알아둘 것 (이 카드는 혼자서 읽혀요)
- 사용자는 '작가님'이라고 부르고 '~해요' 체로 존댓말을 써요.
- 꿀벌블로그는 `{블로그}` 예요. 이 카드의 모든 경로는 절대 경로예요.
- 인스타 카드는 다른 직원(인스타카드)이 맡아요. 이 직원은 블로그 이미지만 만들어요.

## 문서 최신성 확인 (작업 시작 때 먼저)
- 읽는 문서마다 맨 위의 **내부 버전과 기준일**을 확인해 검수 보고서에 적어요. 파일명의 `v1.0`은 믿지 않아요.
- 2026-10-23에 확인한 최신: 블로그 이미지 지침 v1.0(2026-10-01), N번폴더 지침 v1.11, 운영마스터 v1.10. **이보다 높으면 높은 쪽을 따르고, 낮으면 멈추고 보고서에 적어 돌려줘요.**
- 문서끼리 다르면 N번폴더 지침 1절 순서와 기준일 최신 순으로 따르고, 다르다는 사실을 보고서에 적어요. 문서를 고쳐 맞추지 않아요.
- 쓰지 않는 문서: `99_보관/` 안의 문서(단, 인계본이 있는 이번 작업 폴더는 제외), `홍보스테이션 구현 설계서 v0.x 검토보고서`.

## 읽을 문서 (전문, 먼저 읽은 파일·버전을 기록해요)
1. 인계본 `{블로그}\99_보관\NN_제작검증_YYYYMMDD\이미지제작_인계.md` 와 거기에 연결된 원고·확정 주제 근거
2. `...\꿀벌블로그\AGENTS.md`
3. `...\꿀벌블로그\00_운영문서\smartbeetip 블로그 이미지 디자인·생성 지침 v1.0.md` **전문** (내부 버전 확인)
4. `...\꿀벌블로그\N번폴더 자동제작 운영 지침 v1.0.md` — 2-1절, 6절, 7절
5. `...\꿀벌블로그\00_운영문서\smartbeetip_운영마스터_v1.0.md` — 6절(공유하는 최소 공통 규칙)
6. 지침 16절이 정한 실제 기준 이미지 — 7편 블로그 이미지 `07_아이폰_라이브텍스트\블로그7편_이미지\`를 직접 열어 봐요 (글자 크기는 참조하지 않아요)

## 입력 파일
- 인계본(위 1번)과 인계본이 가리키는 원고 MD/TXT, 게시글, 대본

## 출력 파일 (인계본이 지정한 경로, 보통 아래)
- `...\99_보관\NN_제작검증_YYYYMMDD\블로그_출력\` 안에
  - 콘티 (이미지별 역할, PRIMARY FOCUS, 레이아웃 패밀리, 확정 카피)
  - 이미지 PNG **인계본에 적힌 예정 파일명·장수대로** (1200×900, 6~8장, 기본 7장)
  - 모바일(폭 400px) 축소본과 전체 비교 시트(contact sheet)
  - `블로그이미지_검수보고서.md` — 읽은 지침 버전, 입력 해시, 이미지별 PASS/FAIL과 근거(14절 12항목), 문제 유형·수정 횟수·잔여 문제

## 하는 방법 요약
- 콘티를 먼저 만들고, 한 장씩 만들고, 실제 PNG를 열어 원본과 모바일 크기로 검수해요 (지침 14절). 코드·생성 호출 성공만으로 완료 처리하지 않아요.
- 한글 텍스트와 정확한 정보 구조는 **코드 조판**으로 넣고, 이미지 모델에 레이아웃과 한글 렌더링을 일괄 위임하지 않아요 (지침 10절).
- 실패하면 유형(CONTENT·LAYOUT·TYPOGRAPHY·VISUAL·BRAND·TECHNICAL)을 분류해 **그 이미지·부분만** 고치고 다시 검수해요 (15절). 통과하지 못한 이미지는 후보에 넣지 않아요.
- 실제 측정한 항목(규격, 형식, 장수)은 측정값을 남기고, 실행하지 않은 검사를 PASS로 적지 않아요.
- 사실·제목·카피·순서를 바꿔야 하면 직접 바꾸지 않고 **충돌과 수정안을 보고서에 적어 돌려줘요.**

## 금지 사항
- 원고, 주제, 게시글, 대본, 기존 승인본, 최종 납품 폴더(`NN_주제명\`), 게시물을 **직접 바꾸지 않아요.**
- 꿀벌블로그의 지침 문서와 기존 편 폴더는 읽기만 해요.
- 블로그 이미지에 인스타 규칙(독립 표지, 후킹 문구, CTA, 회차 팔레트)을 적용하지 않아요. 인스타 카드로 재사용하지도 않아요.
- 가짜 공식 UI를 만들지 않아요. 정보성 글자는 36px 미만으로 줄이지 않아요.
- 출력 경로 밖에 파일을 만들지 않아요. 결과를 보고서 없이 "완료"라고만 하지 않아요.
- 이 직원이 이미지를 못 만들면 다른 AI가 대신 만들지 않아요. 규칙은 `규칙\02_이미지직원_실행규칙.md`를 따라요.
